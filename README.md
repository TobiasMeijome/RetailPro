M5 - Consultas con JOINs
Descripción
Consultas SQL desarrolladas para RetailPro con el objetivo de relacionar información de clientes, productos, categorías y ventas.
Consultas realizadas
- Consulta 1:** Vista base del proyecto utilizando `INNER JOIN`.
- Consulta 2:** Clientes sin ventas utilizando `LEFT JOIN`.
- Consulta 3:** Productos sin ventas utilizando `LEFT JOIN`.
- Consulta 4:** Consolidado de ventas por canal utilizando `UNION ALL`.
