RetailPro
Descripción

RetailPro es un proyecto de análisis de datos desarrollado para una empresa distribuidora de tecnología. El objetivo es analizar la información de ventas y generar datos útiles para apoyar la toma de decisiones comerciales.

El proyecto abarca distintas etapas, desde la creación y consulta de una base de datos hasta la construcción de un modelo analítico y medidas en Power BI.

Pregunta de negocio

¿Qué factores explican las diferencias en las ventas entre las distintas regiones de RetailPro y qué productos influyen principalmente en esos resultados?

Base de datos

La base de datos utilizada en el proyecto se denomina Ventas_Tech_DB.

Entre las principales tablas utilizadas se encuentran:

clientes
productos
categorias
ventas

Las consultas SQL permiten analizar las ventas, productos y clientes mediante diferentes técnicas de agrupación, filtros y relaciones entre tablas.

Consultas SQL

Los scripts SQL se encuentran organizados dentro de los diferentes módulos del repositorio.

Para ejecutar los scripts:

Abrir SQL Server Management Studio.
Conectarse a una instancia de SQL Server.
Seleccionar la base de datos correspondiente.
Abrir el script SQL que se desea ejecutar.
Ejecutar el script utilizando el botón Execute o la tecla F5.
Power BI

El proyecto también incluye el desarrollo de un modelo analítico en Power BI.

Se utilizan Power Query para la transformación de datos y DAX para la creación de medidas destinadas al análisis de las ventas.

Objetivo del proyecto

El objetivo principal de RetailPro es transformar los datos de ventas en información útil para identificar productos, clientes y períodos relevantes para el negocio y facilitar la toma de decisiones comerciales.
